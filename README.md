# Конвертер величин — веб-версия для iPhone

Та же программа, что `UnitConverter.exe`, но работает в браузере и ставится на экран «Домой» как приложение.
После первой загрузки работает без интернета. Ленты калькулятора и настройки хранятся на самом телефоне.

## Как выложить в интернет (GitHub Pages, бесплатно)

1. Зарегистрируйтесь на <https://github.com> (если ещё нет аккаунта).
2. Справа вверху **+** → **New repository**.
   - Repository name: например `converter`
   - Видимость: **Public** (на бесплатном тарифе Pages работает только с открытыми репозиториями;
     ваши ленты и настройки туда не попадают — они хранятся только на телефоне)
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Откройте папку `web` на компьютере, выделите **всё её содержимое** (файлы и папку `icons`)
   и перетащите в окно браузера. Важно: перетаскивать содержимое, а не саму папку `web`,
   чтобы `index.html` оказался в корне.
5. Внизу нажмите **Commit changes**.
6. **Settings** → слева **Pages** → в «Build and deployment»:
   Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
7. Через 1–2 минуты вверху страницы Pages появится адрес вида
   `https://ваш-логин.github.io/converter/`.

## Как поставить на iPhone

1. Откройте этот адрес в **Safari** (именно в Safari).
2. Кнопка **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Запускайте с иконки — откроется на весь экран, без адресной строки.

## Как обновить

1. Загрузите изменённые файлы в репозиторий тем же способом (Add file → Upload files) — они заменят старые.
2. В `sw.js` увеличьте `VERSION` (например `uc-v1` → `uc-v2`) и тоже загрузите, иначе телефон может
   какое-то время показывать старую версию из кэша.
3. На телефоне закройте и снова откройте приложение (иногда нужно дважды).

## Проверка на компьютере

```
python -m http.server 8765 --directory web
```

и откройте <http://localhost:8765>.
